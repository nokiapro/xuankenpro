Quản lý Video

List Cosplayer

Mỗi dòng là 1 cosplayer. Tag dùng để lọc bài (giống /tag/星之迟迟). Link công khai: cosplayers/

Quản lý Menu

Menu giống site: nhãn + URL tự đặt. Ví dụ URL: ./ (trang chủ), list/?type=photo, list/?type=video, list/?type=all. Bấm nhanh bên dưới để thêm mục có sẵn.

Hệ thống Tag

Tag lấy từ các bài ảnh/video. Bấm đồng bộ để cập nhật số lượng. Lọc trang chủ: ?tag=tên

Token download

Token tạo khi user bấm Tải → trang dl.html đếm 10s. Hết hạn sau 2 phút.

Cài đặt site

Lưu trên Firebase (settings/site). Trang chủ có thể đọc sau khi bạn gắn thêm.
